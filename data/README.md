# MetroMind — Data Directory

This directory will eventually contain validated metro network data, including:

- **stations** — station names, IDs, and coordinates
- **metro lines** — line names, colors, and sequences
- **connections** — edges between stations with distances, travel times, and fares
- **route metadata** — interchange points, service zones, and scheduling data

All data will be stored in JSON format.

> **Note:** Actual metro network data has not been added yet. This directory is reserved for future phases.
